# Governance

The **Governance** folder contains the constitutional, editorial, and operational framework of the **Sanātana Dharma Dharohar** repository.

Every permanent decision affecting the repository's structure, editorial standards, methodology, or long-term direction originates here.

All contributors—human and AI—should become familiar with these documents before making substantive changes to the repository.

---

# Purpose

The governance framework exists to ensure that the repository remains:

- Authentic
- Evidence-based
- Non-sectarian
- Consistent
- Maintainable
- Stable over the long term

Governance documents define **how** the repository is built. They do not contain repository content themselves.

---

# Governance Hierarchy

The repository follows the following governance hierarchy:

1. Constitution.md
2. Decision Ledger.md
3. Project Status.md
4. Project Handover.md
5. AI_EDITOR.md
6. Ādhāra Śilā Methodology.md
7. Ādhāra Śilā Taxonomy.md
8. Ādhāra Śilā Editorial Guide.md
9. Research & Citation Policy.md

When two documents appear to conflict, the higher document takes precedence.

# Contributor Workflow

Before beginning substantive work:

1. Read **Project Status.md**.
2. Review any recent entries in **Decision Ledger.md**.
3. Follow the **Constitution.md**.
4. Apply the editorial methodology and taxonomy.
5. Record new governance decisions separately from editorial work.

---

# Repository Philosophy

The governance framework exists to preserve the long-term integrity of the repository.

Editorial convenience should never override governance, evidence, or authentic representation.

Whenever uncertainty exists:

- Prefer primary sources.
- Preserve traditional distinctions.
- Document differing viewpoints rather than harmonizing them.
- Record governance decisions explicitly.
- Maintain long-term consistency over short-term convenience.
